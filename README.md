## Tata Tertib Laboratorium

Praktikum dilakukan hanya pada aplikasi latihan yang dijalankan sendiri di komputer atau laboratorium kampus.

Pengujian terhadap sistem informasi akademik, jurnal kampus, atau situs pihak lain tanpa izin tertulis tidak diperbolehkan.

Bukti pemeriksaan dapat berupa tangkapan layar, catatan log, cuplikan kode, dan hasil alat pemeriksaan resmi.

Setiap temuan perlu disertai bukti, dampak terhadap CIA, perbaikan, dan bukti bahwa perbaikan berhasil.
